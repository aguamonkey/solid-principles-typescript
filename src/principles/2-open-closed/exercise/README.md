# Exercise · Dispatch room

[Lesson](../README.md)

Add a local inbox strategy, register it, and expose it in the demo. Keep the dispatcher lookup unchanged; test the receipt, an unknown key and duplicate registration.

Before coding, write down the consumer promise, the files you expect to change, and one alternative. Implement the change in your local editor, add a behavioural test, and run `npm run check`.

Explain which existing behaviour stayed stable. Attempt this before reading the [separate solution](../SOLUTION.md). For payload compatibility, continue with the [advanced exercise](../advanced/EXERCISE.md).
